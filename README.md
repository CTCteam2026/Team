## The three objectives, in one line each
- **Page speed** — next-gen images, plugin/JS trim, caching, CWV into "Good".
- **SEO visibility** — de-duplicate pages, keyword→page map, unique titles/meta, deeper service + industry surface area.
- **AI searchability (Gemini)** — unblock AI crawlers, add Organization/LocalBusiness/Service/FAQPage schema, and write self-contained, quotable answer content.
